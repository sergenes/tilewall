date: 2026-11-13

First public release.

- Tiles the windows the rules match, Terminal by default, and grows the focused tile to a quarter of the screen.
- Landscape and portrait layouts.
- Each display has its own group, which moves and resizes like one window.
- Tiling can be switched off per display.
- Menu bar menu, hotkeys under the left hand, and a command line.
- Square window corners are experimental, see the README.
