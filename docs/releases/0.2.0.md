date: 2026-11-16

### New

- **Reorder tiles.** `tilewall move next` and `tilewall move prev` swap a tile with its neighbour. Also in the menu as Move Tile Forward and Move Tile Back, and on ctrl+alt+shift+d and ctrl+alt+shift+a.
- **More terminals out of the box.** A new config tiles Terminal, iTerm2, Ghostty, kitty, WezTerm, Alacritty and Warp. Only Terminal has been tested so far, so reports about the others are welcome. An existing config keeps its rules.
- **Tile any app without editing JSON.** Always Tile in the menu adds a rule for the frontmost app, and `tilewall rule add <app>` does the same from the command line.
- **Update check.** Once a day tilewall asks GitHub whether a newer release exists and shows it at the top of the menu. Nothing is downloaded. `"checkForUpdates": false` in the config switches it off, and `tilewall update` checks on request.

### Better

- **Much less idle work.** Tiling is now driven by window notifications, with a reconcile every 5 seconds instead of every second. With 14 Terminal windows, idle CPU went from about 2.2% to about 0.3% on the Mac it was measured on.
- A group dropped on a display is judged by where the pointer was during the drag.
- A command line client that hangs no longer blocks other `tilewall` commands.
- The disk image opens with the app next to the Applications folder.
